# Code of Conduct

## Our Standard

This project should stay constructive, respectful, and calm.

Please:

- assume good intent
- give clear technical feedback without insults
- keep product criticism focused on the work, not the person
- help make the repo approachable for new contributors

## Unacceptable Behavior

- harassment or intimidation
- personal attacks
- hostile, dismissive, or intentionally belittling comments
- sharing private data without permission

## Scope

This applies to repository discussions, issues, pull requests, and other project communication spaces.

## Enforcement

Project maintainers may remove content or restrict participation if behavior makes collaboration unsafe or unproductive.
